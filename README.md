# Piano-site

A simple placeholder website for private piano lessons in San Diego, CA.

## Pages

- `index.html` — landing page
- `pricing.html` — lesson pricing and a payment placeholder (payment processing not yet connected)
- `about.html` — about the teacher (placeholder bio)

## Running locally

This is a static site with no build step. Open `index.html` directly in a
browser, or serve the folder with any static file server, e.g.:

```
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
